## Description

OneInbox brings your connected email accounts into one clear, focused inbox.

Read messages from all your accounts in a single list, search across inboxes,
open full conversations, and send replies from the right address. Star,
archive, snooze, or delete mail without jumping between email apps.

Features:

- One unified inbox for your connected accounts
- Gmail, Microsoft, iCloud, and custom-domain email support
- Search across all connected inboxes
- Read complete conversations and send replies
- Star, archive, snooze, restore, and delete messages
- Colour-coded accounts that make each mailbox easy to spot
- Encrypted mailbox credentials and private account isolation

An existing OneInbox account with an active plan is required. Purchases and
subscription changes are not offered in the iOS app.

## App Review notes

OneInbox is a free native companion app for the OneInbox email service. It
does not contain purchases, pricing, checkout links, or calls to purchase
outside the app. Reviewers can use the supplied review account to read seeded
messages and exercise inbox actions. Connected provider mailboxes belong to
the reviewer account; no Apple reviewer is expected to connect a personal
mailbox.

Before submission, place a stable review email/password in App Store Connect
and verify it immediately before pressing **Submit for Review**. Never commit
those credentials to this repository.

## App Privacy working answers

OneInbox does not track users across apps or websites and does not sell user
data. The app uses these linked-to-user data types for App Functionality:

- Contact Info → Email Address
- User Content → Emails or Text Messages
- Identifiers → User ID
- Other User Content → email attachments a user chooses to view or send

Confirm the final answers against the production SDK list before submission.
If crash reporting or analytics is added later, update App Privacy before that
build is reviewed.
